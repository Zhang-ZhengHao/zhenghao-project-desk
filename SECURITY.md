# Security Policy

## Current support boundary

This repository is in bootstrap and does not yet accept real project inquiries. No revision is currently production-ready.

When the intake workflow opens, the documentation will identify the supported release, data-retention policy, and private reporting channel. Until then, do not submit secrets, personal information, customer material, or vulnerability details through a public GitHub issue.

## Reporting

Use GitHub Private Vulnerability Reporting when it becomes available for this repository. If you found this project through a freelance platform, you may also contact Zhenghao through that platform without including live credentials or personal data in the first message.

Useful reports include a reproducible description, the affected revision, and synthetic evidence. Never include a real access token, customer record, or production database export.

## Explicit non-claims

The project does not claim PCI, SOC 2, GDPR, or other formal certification. Security controls are application-level evidence and do not replace an independent production assessment.
