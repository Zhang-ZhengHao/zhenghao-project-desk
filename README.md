# Zhenghao Project Desk

Zhenghao Project Desk is a work-in-progress project intake portal for Zhenghao Zhang's independent full-stack development services.

The first release will let a prospective client submit a limited project brief, verify their email address, and receive an honest review status. A private owner workspace will be protected by a GitHub numeric-user-ID allowlist.

## Current status

Repository bootstrap only. The live intake form is not available yet.

- No real inquiries are accepted by this revision.
- No payment, proposal approval, file upload, or electronic-signature feature exists in v0.1 scope.
- Screenshots, fixtures, and test identities will use synthetic data only.
- Never submit passwords, API keys, production data, identity documents, health information, or payment-card data.

## Planned v0.1 evidence

- Next.js and strict TypeScript application
- PostgreSQL migrations with explicit primary/demo runtime isolation
- Transactional email outbox and one-time verification links
- GitHub OAuth owner access based on an immutable numeric user ID
- Desktop and mobile browser tests, accessibility checks, Docker, and CI

The validated design and implementation plan are maintained in the project workspace while bootstrap is in progress. A public architecture summary will remain in [`docs/design-summary.md`](docs/design-summary.md).
